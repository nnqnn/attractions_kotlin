## 📌 Описание проекта

**Путеводитель по достопримечательностям/музеям** — это Android-приложение-путеводитель по достопримечательностям.
Приложение позволяет пользователю просматривать список интересных мест, получать информацию о достопримечательностях и ориентироваться при планировании прогулок или путешествий.

Проект разработан с целью изучения Android-разработки на Kotlin и демонстрации модульной архитектуры приложения.


## 🧰 Стек технологий

Проект написан с использованием следующих технологий:

* 🟣 **Kotlin** — основной язык разработки. 
* 🤖 **Android SDK** — для создания мобильного приложения.
* ⚙️ **Gradle / KTS** — система сборки проекта. 
* 📦 **Модульная архитектура**
  * `app` — основной Android-модуль
  * `weatherlib` — библиотечный модуль с логикой и моделями данных
* **Android Studio**
